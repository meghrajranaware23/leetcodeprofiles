## 🎯 How to Approach Unseen Problems

You've trained on 10 quests and 3 test problems. Real LeetCode won't label the pattern for you. Use this four-step loop on every new problem:

1. **Read for constraints, not details.** In-place? Multiple queries? Fixed alphabet? These narrow the pattern family before you write anything.
2. **Scan the signal table.** Match keywords from the problem statement to your cheat sheet above. Say the pattern name out loud: *"left equals right → prefix thinking."*
3. **Reject brute force in your head.** If your first instinct is nested loops, ask *why* — then reach for the pattern that eliminates the inner loop.
4. **Check the skeleton, not the solution.** You don't need to remember every line of code. You need the structure: read-write pointer, complement map, prefix subtraction, frequency consumption.

If you can name the pattern in under 30 seconds, you've already won half the battle. The code is just filling in the template.
