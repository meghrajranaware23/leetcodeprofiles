## 🔍 Pattern Signals — Recognition Drill

Before you move on, practice **hearing the signal** in each phrase below:

| When you see... | Think... | Why |
|---|---|---|
| "anagram" / "permutation" / "same characters" | Frequency array + increment/decrement | Same multiset, order irrelevant |
| "count occurrences" / "how many times" | `int[26]` or HashMap | Tally beats pairwise compare |
| "first non-repeating" / "first unique" | Two-pass frequency count | Order requires second pass on string |
| "most frequent" / "least frequent" | Frequency count + scan for max/min | Find peak in count array/map |
| "can you form / construct" / "ransom note" | Frequency subset check | Count A must cover count B |
| "lowercase letters only" | `int[26]` not HashMap | Fixed domain → O(1) access, no hashing |
| "find the extra / missing character" | Increment/decrement; non-zero entry | One string is a superset of the other |

## 🎯 Transfer to Unseen Problems

You've seen Valid Anagram and First Unique Character. Can you recognize frequency counting on problems you've never studied?

**Scenario 1:** *"Given a ransom note string and a magazine string, return true if the magazine has enough letters to write the ransom note. Each letter in the magazine can only be used once."*

Which pattern? **Frequency subset check.** Count magazine letters. For each ransom letter, decrement — if any count goes negative, return false.

**Scenario 2:** *"Two strings s and t. String t is generated by random shuffling of s and adding one random letter. Find the letter that was added."*

Which pattern? **Increment/decrement.** ++ for s, -- for t. The index with count +1 is the extra character.

**Scenario 3:** *"Given a string, return the index of the first character that does not repeat anywhere else in the string. Return -1 if none exists."*

Which pattern? **Two-pass frequency.** Pass 1: count all chars. Pass 2: walk the string left to right, return first index where count == 1.

> **Answer key:** All three → frequency counting. The *query* changes (subset check, find extra, find first unique) — the count-first structure does not.

## ⚠ Common Mistakes

1. **Using HashMap when `int[26]` works** — For lowercase-only problems, `int[26]` is faster, simpler, and impresses interviewers more.

2. **Iterating the freq array instead of the string** — For "first unique" problems, iterate the *string* to preserve order.

3. **Forgetting the length check** — If `len(s) != len(t)`, they can't be anagrams. This O(1) check avoids unnecessary work.
