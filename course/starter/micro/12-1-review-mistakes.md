# 📝 Guide: Review Mistakes

> **Day 12** · Mistake Journal Review · 10 XP · 8 min read

---

**Your mission today:** *Your journal is your fastest teacher — use it weekly.*

**Learning objective:** Run a 15-minute weekly review, re-solve one hard problem cold, and compare growth honestly

**Bridge from Day 11:** You tag families. Today you **mine your journal** — the problems you got wrong are worth more than three new Easies.

---

## Part 1 — Mistake Journal Review

### 1. Why weekly review beats problem hopping

New problems feel productive. Re-solving one you got wrong proves whether you actually learned. The journal tells you which one to pick.

### 2. The skill in one sentence

> **List 3 wrongs → re-attempt hardest one cold → compare → one sentence of growth.**

### 3. 15-Minute Weekly Review Template

```
1. List 3 problems you got wrong or needed hints for (5 min)
2. Re-attempt hardest ONE cold — no hints (8 min)
3. Compare: same bug? faster? cleaner? (2 min)
4. One sentence: "This week I stopped ___"
```

### 4. Re-solve comparison rubric

| Question | Growth signal |
|----------|---------------|
| Same approach? | Consistency |
| Faster / fewer hints? | Fluency |
| Cleaner code? | Mastery |
| Same bug again? | Add to mistake mirror |

### 5. What strong reviewers do

| Weak habit | Strong habit |
|---|---|
| Skip weekly review — jump to new problems | 15 min review before new Easies |
| Re-solve without timing comparison | Log minutes: Week 1 vs today |
| Don't log "same bug vs new bug" | Journal one sentence per re-solve |
| Pick easiest re-solve, not hardest | Cold attempt on journal's hardest pick |

### 6. The key insight

> **Faster on a problem you got wrong before is measurable growth** — faster on a brand-new Easy might just be luck.

### 7. Common Day 12 mistakes

| Mistake | Fix |
|---|---|
| Skipped weekly review template — jumped to new problems | Run 15-min template first |
| Re-solved without timing comparison | Note minutes to AC in journal |
| Didn't log "same bug vs new bug" | Compare Day 5 vs today explicitly |
| Chose Majority because it's "easy" not because journal said so | Pick from mistake list |

### 8. Try it now (60 seconds)

Open your journal. Name **one** problem you'd re-solve cold today and **one** thing you'd compare (time, hints, or same bug).
