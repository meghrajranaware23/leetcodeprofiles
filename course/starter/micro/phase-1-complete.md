## 🧠 Your Workflow Cheat Sheet

| When... | Do this... |
|---|---|
| Before opening editor | Read title → constraints → examples → output format |
| Stuck after 5 minutes | Write brute force on paper, then check hints |
| After wrong answer | Re-read examples, add print statements, test n=1 |
| After reading editorial | Close it, re-solve from memory in 24 hours |
| End of each day | Log one mistake and one lesson in your journal |
| Weekly review | Re-attempt 2 problems you got wrong or needed hints for |
| Choosing next problem | Pick same difficulty, same topic family — not random Hard |
| Under time pressure | Read fast, plan 2 min, code, test examples before submit |

> 💡 **The Phase 1 skill:** Read first. Trace second. Code third.
