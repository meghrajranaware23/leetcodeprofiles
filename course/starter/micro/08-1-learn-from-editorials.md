## Part 1 — Productive Editorial Learning

### 1. Why editorials need a protocol

Opening Discuss before trying destroys the attempt-first habit. Reading line-by-line lets you submit without understanding. The protocol keeps editorials as teachers.

### 2. The skill in one sentence

> **Attempt 5+ minutes → read for the idea → close tab → re-solve within 24 hours → one journal sentence.**

### 3. Editorial Protocol (memorize this)

```
① Attempt 5+ minutes (logged stuck point)
② Read editorial for IDEA only — not line-by-line
③ Close tab
④ Re-solve from memory within 24 hours
⑤ One-sentence lesson in journal
```

### 4. Two-pointer intro (Remove Duplicates)

Sorted array — write unique values at front:

```
nums: 1 1 2 2 3
      w
      r→  skip dupes, write new value at w
```

**Slow (`w`):** next write position · **Fast (`r`):** scanner

### 5. Compare approaches (Merge Sorted Array)

| Approach | Trade-off |
|----------|-----------|
| Merge into new array | Easy, extra space |
| Merge from **end** backward | In-place trick — editorial gold |

Read for the idea. Code your own version.

### 6. What strong editorial learners do

| Weak habit | Strong habit |
|---|---|
| Open Discuss before 5-minute attempt | Log stuck point, then read |
| Copy editorial line-by-line | Extract one idea, close tab |
| Never re-solve | Re-solve from memory within 24h |
| No journal line | One-sentence lesson after every editorial |

### 7. The key insight

> **The editorial's job is to change how you think** — not to give you green Submit. If you can't re-solve tomorrow, you didn't learn.

### 8. Common Day 8 mistakes

| Mistake | Fix |
|---|---|
| Copied editorial verbatim — can't re-solve tomorrow | Read for idea, code your version |
| Read editorial before 5-minute attempt | Attempt first, stuck point logged |
| No 24h re-solve scheduled | Block 10 min tomorrow for same problem |
| Skipped one-sentence journal lesson | Write what the editorial did that you didn't think of |

### 9. Try it now (60 seconds)

Name one problem where you'd read an editorial today. Write the **one idea** you'd look for — not the code.
