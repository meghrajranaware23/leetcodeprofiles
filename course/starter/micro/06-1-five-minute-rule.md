# 📝 Guide: The 5-Minute Attempt Rule

> **Day 6** · Attempt-First Discipline · 10 XP · 8 min read

---

**Your mission today:** *Getting stuck is data, not failure.*

**Learning objective:** Commit to genuine attempts before hints; normalize getting stuck

**Bridge from Day 5:** The paper timer is now non-negotiable. Phase 2 rewards **honest stuck points**, not speed.

---

## Part 1 — Attempt-First Discipline

### 1. Why stuck points matter

If you open hints at 30 seconds, you never learn where your process breaks. A stuck-point log turns "I failed" into "I got stuck at ___ after trying ___."

### 2. The skill in one sentence

> **5 minutes of honest attempt → log stuck point → then hints.**

### 3. Stuck-Point Log Template

```
Problem: ___________
Minutes: ___
Stuck at: reading / planning / coding / debugging
I tried: ___________
Next step: hint / break / revisit tomorrow
```

### 4. Attempt-before-hints timeline

| Time | Action |
|------|--------|
| 0–1 min | 4-part read (Day 2) |
| 1–3 min | Paper plan / trace |
| 3–5 min | Code attempt |
| 5+ min | Hints OK — log stuck point first |

### 5. Two-pointer preview (Reverse String)

```
s = h e l l o
    l→      ←r  swap inward until l >= r
```

### 6. What strong beginners do

| Weak habit | Strong habit |
|---|---|
| Open hints at first confusion | Full 5 min with log template ready |
| Blank journal after stuck | "Stuck at: swap condition" — specific |
| Treat stuck as shame | Stuck = data for tomorrow's review |
| Skip trace on two pointers | Draw l and r on paper before coding |

### 7. The key insight

> **Getting stuck is not failure — opening hints before you log what you tried is.**

### 8. Common Day 6 mistakes

| Mistake | Fix |
|---|---|
| Opened hints before 5 minutes | Timer visible; hints after log entry |
| Didn't record what I tried | Fill all 5 lines of stuck-point template |
| Treated stuck as failure | One sentence: "Stuck at X, tried Y" |
| Coded two pointers without trace | Swap h↔o on paper first |

### 9. Try it now (60 seconds)

Open Reverse String — set a 5-minute timer and write one line: *Where will I get stuck if I don't trace?*
