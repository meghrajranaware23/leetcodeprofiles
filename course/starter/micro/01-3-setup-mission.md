# 📋 Setup Mission: Account & Habit Checklist

> **Day 1** · Setup Checklist · 10 XP · 5 min

---

Complete this checklist before moving to today's checkpoint. These are one-time setup tasks — do them once, benefit for all 15 days.

---

## ✅ Account & Profile

- [ ] Create a [LeetCode account](https://leetcode.com/accounts/signup/) (or log in to existing)
- [ ] Set your preferred language in Profile → Settings
- [ ] Bookmark the [Problem List](https://leetcode.com/problemset/) filtered to Easy

> 💡 **Mentor note:** Pick the language you'll use in interviews or at work. Switching mid-path adds friction.

## ✅ Editor Setup

- [ ] Choose your coding environment: LeetCode online editor OR local IDE
- [ ] If local: verify you can run a simple `main` and print output
- [ ] Enable syntax highlighting and auto-indent in your editor

> 💡 **Mentor note:** LeetCode's editor is fine for Starter Path. Local IDE is OK if you already use it daily — not worth learning both at once.

## ✅ Habit Setup

- [ ] Block **20 minutes daily** on your calendar (same time each day)
- [ ] Create a mistake journal (notebook, Notion, or Google Doc)
- [ ] Write your 90-day goal in one sentence at the top of the journal

> 💡 **Mentor note:** Example goal: *"By Day 90 I can solve any Easy and attempt Mediums with a clear workflow."* One sentence. Not a novel.

## ✅ First Win

- [ ] Complete the FizzBuzz warmup quest with an Accepted submission
- [ ] Screenshot or note your first AC — you'll want to remember this

> 💡 **Mentor note:** Green "Accepted" is the milestone. Runtime doesn't matter today.

---

## Submit flow cheat sheet (use on FizzBuzz)

1. **Run** — tests your code on the visible examples only
2. **Submit** — judge runs hidden tests too
3. **Wrong Answer** — read the failing case if shown; fix and Submit again
4. **Accepted** — you're done; log one line in your journal
