### What Makes This Course Different

Most DSA courses teach you **what** arrays are. This course teaches you **how to think** with them.

Here's the approach:

- **Pattern-first learning.** Every day focuses on one pattern. You learn to recognize it, apply it, and extend it — not memorize solutions.
- **Real problems, real code.** Every example uses actual LeetCode problems. No toy examples. No "find the sum of an array" filler.
- **Three languages, always.** C++, Python, and Java — side by side, every day. Pick your weapon or learn all three.
- **Progressive difficulty.** You start with traversals and build to monotonic stacks, Rabin-Karp hashing, and contest-level string problems. The difficulty curve is deliberate.
- **Interview-obsessed.** Pattern recognition signals, common traps, interviewer expectations — baked into every lesson.

## How This Course Works

---

### 30 Days. 30 Missions. 6 Ranks. One Ascension.

This course is structured as a **30-day progressive training system**. Each day is a self-contained mission with a single focus: master one pattern or technique.

You don't skip ahead. You don't cherry-pick. You complete each rank before unlocking the next — just like a hunter ascending through the gates.

### Daily Structure

Every day follows the same battle-tested format:

```
┌─────────────────────────────────────────────┐
│  🎯 Mission       → What you're learning    │
│  📝 Concept        → Deep explanation        │
│  🔍 Pattern Recog  → When & how to spot it   │
│  💻 Code Example   → Real problem, 3 langs   │
│  ⚠️ Common Mistakes → What trips people up    │
│  🏋️ Mini Challenge  → Focused practice        │
│  📚 Practice Probs  → LeetCode assignments    │
└─────────────────────────────────────────────┘
```

This structure is intentional. You learn the *concept*, then learn to *recognize* it in the wild, then *apply* it to real code, then *practice* it yourself. Repetition across modalities is how patterns become instincts.

### The XP System

Every mission earns you **XP (Experience Points)**. XP scales with difficulty:

| Rank    | XP per Mission | Cumulative Range |
|---------|---------------|-----------------|
| E-Rank  | 50–100 XP     | 0–400 XP        |
| D-Rank  | 100–150 XP    | 400–1,025 XP    |
| C-Rank  | 150–200 XP    | 1,025–2,075 XP  |
| B-Rank  | 200–300 XP    | 2,075–3,575 XP  |
| A-Rank  | 300–400 XP    | 3,575–5,325 XP  |
| S-Rank  | 400–500 XP    | 5,325–6,675 XP  |

**Total XP available across the entire course: ~6,675 XP.**

XP is earned by completing the daily mission and practice problems. There are no shortcuts. The XP reflects real skill accumulation.

### Time Commitment

Each day is designed to take **45–60 minutes**:

- ~15 min reading the concept and pattern recognition sections.
- ~15 min studying the code example and understanding the approach.
- ~15–30 min working through the mini challenge and practice problems.

You can absolutely spend more time if you want deeper mastery — the practice problem tables give you extra problems at varying difficulties.

### Rank Tests

At the end of each rank, you'll face a **Rank Test** — a curated set of problems that test everything you've learned in that rank. These aren't new concepts. They're synthesis challenges that force you to combine patterns, handle edge cases, and prove you've internalized the material.

Pass the rank test, and you earn your new rank. Fail, and you revisit. No shame — only growth.

### The Rules of Ascension

1. **Complete days in order.** Each day builds on the previous one.
2. **Complete the rank test before advancing.** No skipping ranks.
3. **Write code, don't just read.** The mini challenges and practice problems are non-negotiable.
4. **Use the pattern recognition sections.** These are the most valuable parts of each day. Study them.
5. **Track your XP.** It's not just a gimmick — it's a measure of genuine progress.

## The Rank System

---

Your journey mirrors the hunter ranking system. Each rank represents a phase of mastery, with progressively harder patterns, tighter constraints, and more complex problems.

---

### ⬛ E-Rank — Foundation

> *"Every S-Rank hunter was once an E-Rank who refused to quit."*

**Days 1–5** · **50–100 XP/day** · **Total: ~400 XP**

You are awakening. The fundamentals aren't glamorous, but they are *everything*. Most people skip this phase and pay for it later when they can't debug a sliding window because they don't understand how iteration actually works on arrays.

In E-Rank, you master:
- Array traversal patterns and mental models
- String manipulation fundamentals
- Frequency counting with hash maps
- The Two Sum pattern and hash map lookups
- Sorting as a problem-solving preprocessor

**What you unlock:** The ability to solve most LeetCode Easy problems cleanly, and the foundational patterns that every advanced technique builds on.

---

### 🔵 D-Rank — Builder

> *"You've learned the basics. Now learn to move with precision."*

**Days 6–10** · **100–150 XP/day** · **Total: ~625 XP**

D-Rank is where you learn to use **pointers** — the single most important technique family in array and string problems. Two pointers, fast/slow pointers, pointer convergence — these show up in easily 30% of all interview questions.

In D-Rank, you master:
- Two-pointer technique (sorted and unsorted arrays)
- Fast & slow pointer patterns
- Three-pointer problems (3Sum and beyond)
- Partitioning and Dutch National Flag
- In-place array modifications

**What you unlock:** The ability to solve O(1) space problems, handle sorted array questions instantly, and recognize pointer-based patterns on sight.

---

### 🟢 C-Rank — Warrior

> *"You don't just solve problems anymore. You see the pattern before you finish reading."*

**Days 11–16** · **150–200 XP/day** · **Total: ~1,050 XP**

C-Rank introduces the **sliding window** and **prefix sum** families — arguably the two most important pattern families for medium-difficulty interview problems. This is where most candidates plateau. You won't.

In C-Rank, you master:
- Fixed-size sliding windows
- Variable-size sliding windows
- Sliding window with hash maps
- Prefix sums and range queries
- Difference arrays
- Kadane's algorithm and subarray problems

**What you unlock:** The ability to handle "subarray" and "substring" problems — the bread and butter of coding interviews. You can now confidently solve most LeetCode Mediums.

---

### 🟡 B-Rank — Commander

> *"Commanders don't just fight. They see the entire battlefield."*

**Days 17–22** · **200–300 XP/day** · **Total: ~1,500 XP**

B-Rank is where you begin stacking patterns and learning advanced data structures that augment your array and string toolkit. Monotonic stacks, matrix traversal, and advanced hashing — these separate strong candidates from exceptional ones.

In B-Rank, you master:
- Monotonic stacks
- Next Greater / Next Smaller Element patterns
- Matrix traversal (spiral, diagonal, layer-by-layer)
- 2D prefix sums
- Advanced hashing techniques
- Interval merging and sweep line basics

**What you unlock:** The ability to handle Hard problems that combine multiple patterns, optimize brute force approaches with clever data structures, and think in two dimensions.

---

### 🟠 A-Rank — Elite

> *"At this level, the problem doesn't challenge you. You challenge the problem."*

**Days 23–27** · **300–400 XP/day** · **Total: ~1,750 XP**

A-Rank is interview mastery. You learn the techniques that show up in Hard problems and final-round interviews: string matching algorithms, advanced two-pointer composites, greedy strategies on arrays, and bit manipulation on strings.

In A-Rank, you master:
- Rabin-Karp rolling hash
- KMP pattern matching fundamentals
- Advanced sliding window composites
- Greedy algorithms on arrays and strings
- Bit manipulation for string problems

**What you unlock:** The confidence to tackle any arrays or strings problem in a 45-minute interview. You're operating at the level of the top 5% of candidates.

---

### 🔴 S-Rank — Legend

> *"You've reached the pinnacle. The final gate awaits."*

**Days 28–30** · **400–500 XP/day** · **Total: ~1,350 XP**

S-Rank is the final ascension. These days synthesize everything — multi-pattern problems, contest-level challenges, and real-world system design scenarios involving arrays and strings. This is where hunters become legends.

In S-Rank, you master:
- Multi-pattern synthesis (combining 2–3 patterns in one solution)
- Contest-level array problems
- Contest-level string problems
- The complete pattern library — reviewed, connected, and internalized

**What you unlock:** Mastery. You can walk into any coding interview, any contest, any technical challenge involving arrays and strings — and perform at the highest level.

## Prerequisites

---

Before you begin your ascension, make sure you have these foundations in place.

### Required

| Skill | What You Need |
|-------|--------------|
| **Programming basics** | You can write programs in at least one of: C++, Python, or Java. |
| **Arrays** | You know what arrays/lists are, how to create them, access elements by index, and iterate through them. |
| **Loops** | You're comfortable with `for` loops, `while` loops, and nested loops. |
| **Conditionals** | `if`/`else` logic is second nature. |
| **Functions** | You can write and call functions, understand parameters and return values. |
| **Basic data structures** | You've seen hash maps/dictionaries and know what they do (even if you don't use them fluently yet). |
| **Some LeetCode experience** | You've solved at least a few Easy problems. You know what the platform looks like. |

### Not Required

- ❌ Advanced mathematics or discrete math.
- ❌ Competitive programming experience.
- ❌ Knowledge of trees, graphs, or dynamic programming.
- ❌ Familiarity with Big-O notation (we cover it on Day 1).
- ❌ A computer science degree.

If you can write a function that loops through an array and counts how many elements are greater than a given value — you're ready.
